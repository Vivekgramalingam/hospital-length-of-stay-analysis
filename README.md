# Hospital Length of Stay Analysis

This repository contains the analysis of the length of stay (LOS) of patients in a hospital, exploring factors contributing to LOS and performing data preprocessing tasks on a dataset of hospital admissions.

## Overview

This project aims to perform data cleaning, preprocessing, and analysis on the provided hospital admissions dataset. The tasks include:
- Calculating the length of stay for each patient.
- Removing outliers based on standard deviation analysis.
- Visualizing the distribution of the length of stay using histograms.
- Identifying and analyzing factors contributing to length of stay, such as ethnicity, admission type, and patient demographics.
- Merging multiple datasets and performing feature engineering for machine learning purposes.
